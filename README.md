# PyLZ77
A simple file compressor and decompressor based on the **LZ77 algorithm** in Python.

## Table of Contents

- [Installation](#Installation)
- [Usage](#Usage)
  - [Compress](#Compress)
  - [Decompress](#Decompress)
- [License](#License)

## Installation

Clone the repository or download the code:
```bash
git clone https://github.com/ItsAeth/lz77-compressor.git
```

## Usage
### Compress
```
python3 run.py -c --lwsize (int) --swsize(int) input output
```
### Decompress
```
python3 run.py -d input output
```
